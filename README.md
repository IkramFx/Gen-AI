# Gen-AI

Repository kumpulan tugas Generative AI. Seluruh materi dan latihan berada di folder [Phase 1](Phase%201/).

## Mulai Cepat

```powershell
git clone https://github.com/IkramFx/Gen-AI.git
cd Gen-AI
cd "Phase 1"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Panduan lengkap instalasi dan pemakaian tersedia di [Phase 1/README.md](Phase%201/README.md).
